About this machine & references

A cash-first, physical-button machine inspired by GLORY’s VT-B20 family. Both practice shops use separate tickets and manual change return. Other shops may return change automatically or send orders straight to the kitchen. Read their signs.

The menu and prices are fictional. The shoyu illustration is generated. Sounds use edited recordings of real mechanisms, not recordings of this GLORY model. No real payment is taken.

GLORY hardware reference · Photographed shop walkthrough · A different shop’s routine

Hakata menu and ordering references: Issou menu · Gatton refill instructions · Ikkousha on noodle firmness. This practice shop uses a representative menu and four firmness choices; it is not a replica of any one restaurant.

Sound recordings (CC0): Licorne_En_Fer, Krokulator, florian_reinke.
